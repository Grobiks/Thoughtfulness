## Как запустить

Colab:

1. Открыть https://colab.research.google.com/, "Файл" -> "Загрузить блокнот", выбрать `dz1-attention.ipynb`.
2. "Среда выполнения" -> "Сменить среду выполнения" -> T4 GPU.
3. "Среда выполнения" -> "Выполнить все". В конце должно быть `пройдено 17 из 17`.
4. То же самое для `dz1-bughunt.ipynb`. Должно получиться:
   - проверки `пройдено 17 из 17`;
   - потери за 600 шагов падают с 3.18 до примерно 0.04;
   - сохраняются `loss_curve.png` и `generated_sample.txt` (в Colab они во вкладке "Файлы" слева);
   - в тексте генерации повторяется фраза "алгоритм внимания смотрит на все позиции сразу."
5. Последняя ячейка в `dz1-bughunt.ipynb` печатает версии Python, PyTorch и есть ли GPU.

Kaggle: Create -> New Notebook -> File -> Import Notebook, в Session options поставить Accelerator GPU T4 x2 (или None), потом Run All. Файлы появятся в панели Output (`/kaggle/working`).

Ячейки нужно запускать по порядку сверху вниз.

Выводы в ноутбуках получены на Kaggle с T4, потому что в Colab в тот момент не давали GPU. Код от среды не зависит.

## Воспроизводимость

- Seed: `torch.manual_seed(0)` перед обучением (был в ноутбуке) и перед генерацией (добавил сам, потому что `torch.multinomial` случайный). В проверках свои фиксированные seed.
- Обучение в ноутбуке идет на CPU, модель на GPU не переносится. Поэтому GPU на результат не влияет. Я запускал на Kaggle (Linux, T4, torch 2.11) и у себя на Windows (CPU, torch 2.12), потери `3.1844 -> 0.037` и текст генерации совпали полностью.
- Параметры обучения: `vocab_size` равен числу разных символов в корпусе (19), `context_size=64`, `d_model=128`, `n_heads=4`, `n_layers=2`, `dropout=0.1`, AdamW, `lr=3e-4`, батч 32, 600 шагов.
