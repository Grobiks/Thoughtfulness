## Как воспроизвести с нуля

Нужен только браузер: всё работает в бесплатном Google Colab, ничего скачивать не нужно.

1. Открыть [Google Colab](https://colab.research.google.com/) → «Файл» → «Загрузить блокнот» → выбрать
   `dz1-attention.ipynb`.
2. «Среда выполнения» → «Сменить среду выполнения» → **T4 GPU** (код работает и на CPU, но ТЗ
   требует T4).
3. «Среда выполнения» → «Выполнить все». В последней ячейке должно быть
   `пройдено 17 из 17` и `Все проверки зелёные.`
4. Повторить шаги 1–3 для `dz1-bughunt.ipynb`. Ожидаемый результат:
   - проверки: `пройдено 17 из 17`;
   - обучение (600 шагов) печатает потери, которые падают примерно с 3,18 до ~0,04;
   - появляются график `loss_curve.png` и файл `generated_sample.txt` (в Colab они лежат во
     вкладке «Файлы» слева, их можно скачать);
   - сгенерированный текст повторяет фразу корпуса «алгоритм внимания смотрит на все позиции сразу.»
5. Последняя ячейка шага 2 печатает конфигурацию окружения (версии Python и PyTorch, наличие GPU).

Ячейки нужно выполнять строго сверху вниз: каждая опирается на объекты из предыдущих.

**То же на Kaggle.** Create → New Notebook → File → Import Notebook, в Session options выбрать
Accelerator **GPU T4 x2** или None, затем Run All. Файлы `loss_curve.png` и `generated_sample.txt`
появятся в панели Output (`/kaggle/working`). Выводы в сохранённых ноутбуках получены именно так:
в момент сдачи Colab не выделял GPU. Код от среды не зависит.

## Воспроизводимость

- **Seed зафиксирован:** `torch.manual_seed(0)` стоит перед обучением и (добавлено мной) перед
  генерацией, потому что генерация сэмплирует случайно через `torch.multinomial`. Проверки
  внутри используют собственные фиксированные seed (0–7).
- **Устройство:** цикл обучения в ноутбуке не переносит модель на GPU и работает на CPU. Поэтому
  числа повторяются один в один от запуска к запуску, а T4 на результат не влияет. Проверено:
  Kaggle (Linux, T4, torch 2.11) и локальный Windows (CPU, torch 2.12) дали одинаковые потери
  `3.1844 → 0.037` и одинаковый текст генерации.
- **Конфигурация модели в обучении:** `vocab_size` = число уникальных символов корпуса,
  `context_size=64`, `d_model=128`, `n_heads=4`, `n_layers=2`, `dropout=0.1`, AdamW с `lr=3e-4`,
  батч 32, 600 шагов.
- **Окружение, на котором проверено:** см. раздел «Окружение» в `REPORT.md`.
